- 预算：按分类查看每月预算、已花、剩余和超支提醒。
- 文档：查看账户和交易的票据与附件。
- 编辑、复制或删除交易；高级编辑器支持多条分录、成本和价格。
- 保存后可直接“查看”刚记的交易；重试保存不会重复记账。
- 分步添加服务器，可先试用演示服务器。
- 自定义 Header（如 Cloudflare Access）可与登录方式同时使用；通过 http 明文发送凭据前需要你确认。
- 浏览器登录启用 PKCE，更安全；编辑不会覆盖服务器上已有的改动。
